# Data files for R Journal submission

The main article folder keeps only the data files needed to render
`grouper.Rmd`. Additional anonymized raw inputs, derived outputs, and
reproducibility scripts are provided in `supplementary.zip`.

Files used directly by the article:

- `raw/ay2520/students.csv`: anonymized student IDs and workload fields
  (`year`, `past_ta`, `past_gr`).
- `raw/ay2520/demand.csv`: anonymized course-level demand by role (`TA`, `GR`,
  `E`) with synthetic course codes (`C01`, `C02`, ...).
- `raw/ay2520/preferences_long.csv`: long-form preference scores by
  `student_id`-`course_code`.
- `derived/multi_role_dataset_summary.csv`: semester-level dataset sizes and
  role-demand totals.
- `derived/ay2520_solver_runtime.csv`: runtime summaries generated by repeated
  open-source solver runs.

The raw files intentionally contain no names, emails, intake dates, original
course codes, or workbook metadata. To regenerate all derived outputs, extract
`supplementary.zip` into the article root and follow `scripts/README.md`.
